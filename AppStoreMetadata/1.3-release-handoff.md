1.3 is an app-side feature release (search refinement, advanced search,
cross-collection search, Collections rework, onboarding, iPad pinch-zoom, and the
CloudKit single-source-of-truth finalisation). It ships against the existing
managed catalog API; no catalog redeployment was performed as part of this cut.

## Headline Changes

- Tap-to-refine search and oracle-text include/exclude, with always-hidden terms.
- Advanced search form with live, colour-coded Scryfall syntax in the search field.
- Cross-collection search with dashboard match surfacing.
- Lists renamed to Collections; on-card add/create/move-category and reordering.
- iPad pinch-to-zoom for the card grid and a resizable collections dashboard.
- Interactive onboarding walkthrough, replayable from Settings and the macOS Help menu.
- iCloud is now the single source of truth; the repeating sync prompt and the
  interactive "Review iCloud Data" conflict screen are removed.
- Removed the plain-text AI search feature.

1. Upload all three packages via `upload-builds.sh` (altool); wait for processing.
2. Re-run `asc-state.sh 1.3 2026062601` and confirm each build is `VALID` and each
   platform version is still `EDITABLE`.
3. `submit.sh` syncs `listing-copy.md` → fastlane metadata and runs
   `fastlane deliver` per platform to attach the build, push metadata, and submit.
   - visionOS uses fastlane's `xros` platform token (fastlane 2.236.1 installed);
     verify the visionOS deliver step is accepted.
4. Automatic immediate release after approval; no phased release.
5. Record TestFlight, review submission, approval, and live-store state as
