## Release

- App Store Connect app ID: `6771003115`

- Release mode: automatic immediately after approval; phased release disabled

1.7 is a data-delivery + performance release. The headline change is
**incremental catalogue updates**: when the managed card catalogue changes, the
app now downloads only the differences from the installed version (a delta chain)
instead of re-downloading the entire ~126 MB database each time. A consecutive
daily update is typically well under a megabyte; a multi-day catch-up is larger
but always ≤ a full download, and any client that can't walk the chain (or fails
verification) falls back to a full download. Every downloaded update is verified
against a per-build logical content digest before it is applied, and the current
library stays usable throughout. A new **Automatic Data Updates** setting lets a
user decline automatic downloads and refresh manually.

Alongside that, a batch of **performance** fixes: card art is decoded off the main
thread before display (smoother scrolling), in-list search is debounced and moved
off the main thread (no more typing freeze), and per-edit list-overview recompute
is scoped to the changed list only (category/quantity edits stop stalling large
libraries). Collection refinements round it out: shadow/ghost multi-category
tiles, a Maybeboard prompt for full Commander decks, and the Magic card back as
the art placeholder.

No new permissions are introduced; no account is required; iCloud remains
optional. No user data is sent to fetch catalogue data.

**Infra performed for this release (done this cut):** the `grimora-data-api`
service was redeployed to Fly with the new `GET /v1/catalog/chain` and
`/v1/catalog/:version/delta/:base` routes (additive; existing routes and older
clients unaffected). This also fixed a latent failure where the API had stopped
building for Linux once Scry/CloudKit pulled Apple-only frameworks into
GrimoraCore — the API target no longer links GrimoraCore. The Mac data-engine
binary was rebuilt/reinstalled with delta generation; the first deltas are
published and the chain is self-sustaining on the nightly schedule. Verified
end-to-end against the live API by an opt-in integration test
(`ProdApiIntegrationTests`, `GRIMORA_PROD_API_TEST=1`): full-download install of
the current catalogue (115,874 cards) and a real HTTP delta download + apply that
reproduces the target content digests.

## Headline Changes

- Incremental catalogue updates: engine generates a `previous → this` delta each
  build (`CatalogDeltaBuilder`), published to Tigris with a windowed `chain.json`;
  the client (`LibraryUpdateService.downloadAndInstallCatalogIncrementally` for the
  in-place ongoing path, `ManagedCatalogMigrationService.stageIncrementally` for the
  staged/migration path) patches a copy of the installed catalogue, verifies it
  against the build's `CatalogContentDigest`, and swaps it in — falling back to a
  full download on any mismatch, missing base, multi-schema gap, or oversized path.
  Value series ship as slide-encoded byte suffixes; daily volatile card columns
  (prices, edhrec/penny rank, image URLs) ship as narrow per-field changes rather
  than full rows.
- Automatic Data Updates toggle: `GrimoraAppModel.automaticCatalogUpdatesEnabled`
  (persisted, default on) gates the launch auto-download; the check still runs so an
  available update is surfaced. Toggle in the library maintenance menu + macOS
  Library commands; manual "Check for Updates"/"Import Available Update" ignore it.
- Scroll performance: `LocalCardImageLoader` runs `preparingForDisplay()` off-main
  so a cached tile becomes a blit (iOS/visionOS; macOS NSImage parity added), plus
  opt-in hitch HUD/log tooling (`GRIMORA_PERF_HUD`, `com.grimora.perf`) and a
  jump-to-top re-render fix.
- In-list search: debounced and run off the main thread (fix the search freeze).
- List-overview recompute: only the actively-changed list recomputes its dashboard
  top-card per edit instead of every list (fix category-change lag).
- Collection refinements: empty secondary categories stay hidden until needed;
  multi-category cards render as dimmed ghost tiles; Maybeboard offered when a full
  Commander deck gains another card; Magic card back as the art placeholder; macOS
  "Toggle Foil" command.
